    Create `src/core/circuit_breaker.py` with:

    1. `CircuitState` enum: CLOSED, OPEN, HALF_OPEN (values: "closed", "open", "half_open")

    2. Module constants: `DEFAULT_THRESHOLD = 3`, `DEFAULT_COOLDOWN_S = 30`

    3. `is_transient_llm_error(exc: Exception) -> bool` function:
       - Check `isinstance(exc, ServerError)` with `getattr(exc, 'code', 0) in {429, 503}`
       - Check `isinstance(exc, ChatGoogleGenerativeAIError)` and unwrap `exc.__cause__` to check if it's `ClientError` with code in `{429, 503}`
       - Check `isinstance(exc, httpx.TimeoutException)` — returns True
       - All other exceptions return False
       - Import types: `from google.genai.errors import ClientError, ServerError`, `from langchain_google_genai.chat_models import ChatGoogleGenerativeAIError`, `import httpx`

    4. `CircuitBreaker` class:
       - `__init__(self, threshold=DEFAULT_THRESHOLD, cooldown_s=DEFAULT_COOLDOWN_S)`: threading.Lock, CircuitState.CLOSED, failure_count=0, opened_at=None
       - `state` property: returns current state (thread-safe read under lock)
       - `check() -> bool`:
         - CLOSED: return True
         - OPEN: check `time.monotonic() - opened_at >= cooldown_s` — if yes, transition to HALF_OPEN and return True (log transition); if no, return False
         - HALF_OPEN: return True (allow probe)
         - All under lock
       - `record_success()`: Under lock — if HALF_OPEN, log transition to CLOSED; set state=CLOSED, failure_count=0, opened_at=None
       - `record_failure()`: Under lock — increment failure_count; if HALF_OPEN, transition to OPEN with fresh opened_at (log); elif failure_count >= threshold, transition to OPEN (log)

    5. Logging: Use `logging.getLogger(__name__)` with `logger.info("circuit_breaker_transition", extra={"from": ..., "to": ..., ...})` for all state transitions. This matches the project's structlog pattern.

    6. Use `time.monotonic()` for cooldown timing (not wall clock).

    Then create `tests/core/test_circuit_breaker.py` with all behavior tests listed above.
