  <action>
    Create `src/core/cycle_store.py` as a core leaf module (NO imports from src.graph.*).

    Functions to implement:

    1. `load_cycle(cycle_id: int, base_dir: str = "data/cycles") -> CycleSnapshot`:
       - Build path: `Path(base_dir) / str(cycle_id).zfill(CYCLE_ID_PAD_WIDTH) / "snapshot.json"`
       - Raise `FileNotFoundError` with descriptive message if path missing
       - Read JSON, return `CycleSnapshot.model_validate(data)`
       - Import CYCLE_ID_PAD_WIDTH from src.core.cycle_snapshot

    2. `list_cycles_filesystem(base_dir: str = "data/cycles", symbol: str | None = None, status: str | None = None, limit: int | None = None) -> list[dict]`:
       - Scan `Path(base_dir)` subdirectories for snapshot.json files
       - Parse each to extract metadata: cycle_id, symbol, status, timestamp, consensus_score (from weighted_consensus_score)
       - Sort by timestamp descending (newest first)
       - Apply symbol/status filters if provided
       - Apply limit if provided
       - Return empty list if base_dir does not exist
       - Do NOT load full CycleSnapshot — just json.loads and extract keys for speed

    3. `async def list_cycles_db(pool, symbol: str | None = None, status: str | None = None, limit: int | None = None) -> list[dict]`:
       - Query cycle_snapshots table: SELECT cycle_id, symbol, status, timestamp, consensus_score
       - Build WHERE clause from filters, ORDER BY timestamp DESC
       - Apply LIMIT if provided
       - Return list of dicts with same keys as filesystem version for interface consistency

    4. `async def list_cycles(pool=None, base_dir: str = "data/cycles", symbol: str | None = None, status: str | None = None, limit: int | None = None) -> list[dict]`:
       - If pool is not None, try list_cycles_db; on any exception, fall back to filesystem
       - If pool is None, use list_cycles_filesystem directly
