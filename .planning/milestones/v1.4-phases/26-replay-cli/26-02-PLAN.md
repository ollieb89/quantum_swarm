       - Add "list" sub-parser with --symbol, --status, --limit (int), --json flags

       - Dispatch to handle_list, handle_show, or handle_compare based on args.replay_command
       - If no replay_command given, print replay help and return 1
       - Returns exit code (0 success, 1 error)

    3. `handle_list(args) -> int`:
       - Get pool via _try_get_pool pattern (try/except import from src.core.db)
       - Call `asyncio.run(list_cycles(pool, symbol=args.symbol, status=args.status, limit=args.limit))`
       - Default limit to 20 if not specified (Claude's discretion)
       - --json mode: `print(json.dumps(cycles, indent=2, default=str))`
       - Rich mode: Table with columns ID (cyan, right-justified), Symbol (bold), Status (colored by value: green=completed, yellow=rejected, red=failed), Timestamp, Score
       - Use `Console()` (auto TTY detection handles pipe degradation)

    4. `handle_show(args) -> int`:
       - Call `load_cycle(args.cycle_id)` — catch FileNotFoundError, print error, return 1
       - --json mode: `print(json.dumps(snapshot.model_dump(mode="json"), indent=2, default=str))`
       - Rich mode: render sections in order using rich Panels:
         a. **Header panel**: cycle_id, symbol, status, timestamp
         b. **Agent Memos panel**: macro_report, quant_proposal, bullish_thesis, bearish_thesis — each as a sub-panel. Extract "analysis" or first key as summary text. Handle None gracefully with "No data" placeholder.
         c. **Debate panel**: debate_history rounds (numbered), debate_resolution summary
         d. **Consensus & Merit panel**: weighted_consensus_score as headline, then merit_scores as horizontal bar charts:
            ```
            AXIOM      ██████████████████ 0.35
            MOMENTUM   ████████████████████████ 0.48  ⚠ DRIFT: voice_tone
            CASSANDRA  ██████████████████████ 0.44
            ```
            Bar width = int(composite * 30). Use rich.Text for colored bars (green).
            For drift annotations: check soul_sync_context for each agent — if present, note it. For ARS suspension: attempt DB query via _try_get_pool; if DB unavailable, show "DB required for suspension status".
         e. **Decision Card panel**: render decision_card dict as key-value pairs
         f. **Error panel** (if status=failed): show error_context

    5. `handle_compare(args) -> int`:
       - Load both cycles via load_cycle — catch FileNotFoundError for either
       - **Same-symbol enforcement**: if snap_a.symbol != snap_b.symbol, print error "Cannot compare cycles with different symbols ({a} vs {b})", return 1
       - Compute deltas (inline helper or import from cycle_store):
         - consensus_score: from, to, delta
         - merit_shifts: per agent composite from, to, delta
       - --json mode: print structured delta dict with from/to/delta for all numeric fields
       - Rich mode: Sequential layout (NOT side-by-side):
         a. **Header**: "Comparing Cycle {a} vs Cycle {b} ({symbol})"
         b. **Consensus delta**: show old -> new with delta and directional arrow
         c. **Merit weight shifts table**: Agent | From | To | Delta columns, with directional indicators:
            - Delta > 0: green "▲ +0.05"
            - Delta < 0: red "▼ -0.03"
            - Delta == 0: dim "  0.00"
         d. **Agent reasoning summary**: For each agent, show first line (or "analysis" key) from each cycle's memo side by side to illustrate shift
