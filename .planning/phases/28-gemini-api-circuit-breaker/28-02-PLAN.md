    **Step 6: Update CycleRunner status determination**:
    In `run_cycle`, after determining status but before `_extract_snapshot`, add logic: if `soft_failed_nodes` is non-empty and status would be "completed", keep status as "completed" but the `degraded` flag handles it. The graph routes to hold naturally when all LLM nodes soft-fail (debate gets empty inputs -> score 0 -> hold -> END), so status will be "completed" with no `execution_result`. The existing `validate_completed()` only runs for status="completed", but a degraded cycle that goes to hold never reaches merit_updater/order_router, so `execution_result` will be None. To avoid ValueError, add status="degraded" to the `Literal` in CycleSnapshot OR (simpler) skip `validate_completed()` when `degraded=True`. Use the simpler approach: in `run_cycle`, after `snapshot = self._extract_snapshot(...)`, only call `snapshot.validate_completed()` if NOT degraded.
