  <files>src/memory/service.py, src/cli/prune.py, tests/cli/test_prune.py</files>
  <behavior>
    - list_documents() returns empty list for empty collection
    - list_documents() groups chunks by document_id and reassembles into StoredDocument
    - list_documents() sorts chunks by chunk_index within each document
    - _render_archive_markdown() produces valid YAML frontmatter delimited by --- markers
    - _render_archive_markdown() includes document_id, source, timestamp, ingested_at, content_hash, and all original metadata (excluding chunk_id, chunk_index, chunk_count)
    - _render_archive_markdown() reassembles chunks into body separated by double newlines
    - _compute_protection_cutoff() returns None when no active rules exist
    - _compute_protection_cutoff() returns oldest active rule created_at when rules exist
    - Documents with timestamp newer than protection cutoff are marked "protected"
    - Documents with timestamp older than threshold AND older than protection cutoff are marked "archive"
    - Documents with timestamp newer than threshold are marked "skip" (too recent)
    - --dry-run mode does NOT write files or delete from ChromaDB
    - Default mode writes .md files and deletes from ChromaDB
    - Idempotent: if archive .md already exists, skip writing but still delete from ChromaDB
    - --no-archive mode deletes without writing archive files
    - Graceful degradation: if ChromaDB unreachable, returns exit code 1 with warning log
    - structlog logs document_archived event per document with document_id, source, chunk_count
    - structlog logs prune_complete summary with archived, deleted, protected, skipped counts
  </behavior>
  <action>
1. Add `list_documents()` method to `MemoryService` in `src/memory/service.py`:
   - Call `self._collection.get(include=["documents", "metadatas"])` to fetch all entries
   - Group by `document_id` metadata field using `defaultdict(list)`
   - Sort chunks within each group by `chunk_index`
   - Return `list[StoredDocument]` with chunks reassembled
   - Handle empty collection (return [])

2. Create `src/cli/prune.py` following the `src/cli/replay.py` pattern:
   - `register_prune_parser(sub)`: add "prune" subcommand with `--dry-run`, `--days N` (default 90), `--no-archive` flags
   - `handle_prune(args) -> int`: top-level dispatch, returns exit code
   - Internal helpers:
     - `_render_archive_markdown(doc: StoredDocument) -> str`: YAML frontmatter via `yaml.dump(default_flow_style=False, sort_keys=False)` + body from joined chunks
     - `_compute_protection_cutoff(registry: MemoryRegistry) -> datetime | None`: min(r.created_at for active rules) or None
     - `_classify_documents(docs, threshold_dt, cutoff_dt) -> list[tuple[StoredDocument, str]]`: returns (doc, action) where action is "archive", "protected", or "skip"
     - `_parse_timestamp(ts: str) -> datetime`: use `datetime.fromisoformat(ts.replace("Z", "+00:00"))` pattern from memory/tools.py
   - Prune flow in handle_prune:
     1. Init MemoryService, check health_check() -- if False, log warning, return 1
     2. Init MemoryRegistry, call get_active_rules()
     3. Compute threshold datetime = now - timedelta(days=args.days)
     4. Compute protection cutoff from active rules
     5. Call svc.list_documents(), classify each document
     6. If dry-run: render Rich table (document_id, source, timestamp, chunk_count, action) + summary line, return 0
     7. If not dry-run: for each "archive" document:
        a. Compute archive_path = `quantum-swarm/Archives/memory/{source.value}/{document_id}.md`
        b. If archive_path exists, skip writing (idempotent) but still mark for ChromaDB deletion
        c. Else: mkdir(parents=True, exist_ok=True), write rendered markdown via tmp + os.replace
        d. Delete from ChromaDB via svc.delete(document_id, node="prune")
        e. Log document_archived event via structlog
     8. Log prune_complete summary event
   - Use `import logging; logger = logging.getLogger(__name__)` for structlog (project convention)

3. Create `tests/cli/test_prune.py` with unit tests (write tests FIRST per TDD):
   - Mock MemoryService with injected collection (use chromadb mock or MagicMock for _collection)
   - Mock MemoryRegistry with controlled active rules
   - Use tmp_path fixture for archive output directory
   - Test cases per behavior list above
