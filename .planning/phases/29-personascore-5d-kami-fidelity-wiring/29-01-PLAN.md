Create `src/core/persona_scorer.py` with:

1. **Pydantic models:**
   - `PersonaScoreResult(BaseModel)` -- 5 float fields (consistency, tone, logic, depth, bias) each `Field(ge=0.0, le=1.0)`, rationale str, `@property composite` = simple average rounded to 4 decimal places.
   - `PersonaScoreEntry(BaseModel)` -- soul_handle, all 5 floats, composite, rationale, fallback bool (default False).

2. **Mappings (duplicated from memory_writer -- Import Layer Law):**
   - `HANDLE_TO_AGENT_ID = {"AXIOM": "macro_analyst", "MOMENTUM": "bullish_researcher", "CASSANDRA": "bearish_researcher", "SIGMA": "quant_modeler"}`
   - `HANDLE_TO_OUTPUT_FIELD = {"AXIOM": "macro_report", "MOMENTUM": "bullish_thesis", "CASSANDRA": "bearish_thesis", "SIGMA": "quant_proposal"}`

3. **Lazy LLM init:**
   - `_judge_llm = None; def _get_judge_llm()` pattern using `ChatGoogleGenerativeAI(model="gemini-2.5-flash", temperature=0.0)` with `.with_structured_output(PersonaScoreResult)`.

4. **Separate CircuitBreaker instance:**
   - `_scorer_breaker = CircuitBreaker(threshold=3, cooldown_s=30)` -- module-level, separate from graph breaker.

5. **`_build_judge_prompt(soul: AgentSoul, agent_output: dict, soul_handle: str) -> str`:**
   - Constructs evaluation prompt including full soul files (IDENTITY.md, SOUL.md, AGENTS.md content), the agent's output, and a rubric for 5 dimensions. The rubric should explain each dimension clearly (Consistency = alignment with stated beliefs, Tone = voice match, Logic = reasoning rigor, Depth = thoroughness, Bias = appropriate directional stance per role where 1.0 = well-calibrated).

6. **`async def evaluate_agent(soul_handle: str, agent_output: dict | None, cycle_id: int) -> PersonaScoreResult | None`:**
   - Returns None if agent_output is None (degraded cycle skip).
   - Returns None if circuit breaker is open.
   - Loads soul via `load_soul(HANDLE_TO_AGENT_ID[soul_handle])`.
   - Builds prompt, calls `await _get_judge_llm().ainvoke(prompt)`.
   - On success: `_scorer_breaker.record_success()`, return result.
   - On exception: `_scorer_breaker.record_failure(exc)`, log warning, return None.

7. **`async def evaluate_all_agents(agent_outputs: dict[str, dict | None], cycle_id: int) -> dict[str, PersonaScoreEntry]`:**
   - Creates tasks for each of the 4 handles using evaluate_agent().
   - `results = await asyncio.gather(*tasks, return_exceptions=True)`.
   - For each result: if PersonaScoreResult, create PersonaScoreEntry; if Exception/None, call `get_latest_persona_composite(handle)` for fallback and create entry with fallback=True and previous composite spread across all 5 dims (or 0.5 if no previous).
   - Returns dict mapping soul_handle -> PersonaScoreEntry.

8. **`async def persist_persona_scores(cycle_id: int, scores: dict[str, PersonaScoreEntry]) -> None`:**
   - Uses `ensure_pool_open()`, inserts one row per agent into `persona_scores` table.
   - Logs errors but does not raise.

9. **`async def get_latest_persona_composite(soul_handle: str) -> float | None`:**
   - Queries `SELECT composite FROM persona_scores WHERE soul_handle = %s ORDER BY scored_at DESC LIMIT 1`.
   - Returns None if no rows.
