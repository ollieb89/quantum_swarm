    1. `CycleRunner` class:
       - `__init__(self, graph, db_pool=None, execution_mode="paper")` — stores graph reference and optional db_pool. No graph imports (dependency injection per CONTEXT.md).
       - `async _allocate_cycle_id(self, symbol: str) -> int` — INSERT placeholder row into cycle_snapshots with status='running', task_id placeholder, symbol. Returns SERIAL cycle_id via `RETURNING cycle_id`. If db_pool is None, return a timestamp-based fallback ID.

         1. Allocate cycle_id from PostgreSQL

         4. except Exception: build failed snapshot with error_context
         5. Extract snapshot, validate_completed() for completed, write file, update DB row
         6. Return CycleSnapshot
