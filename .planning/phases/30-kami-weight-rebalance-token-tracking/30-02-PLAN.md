<objective>
Add per-agent per-cycle token usage tracking from BudgetManager through CycleSnapshot to the replay CLI display, making every cycle's LLM cost observable.

Purpose: Token costs are currently only tracked at session level with no per-agent attribution or cycle persistence. This makes cost optimization impossible -- operators cannot see which agents consume the most tokens or track cost trends over time.

Output: Extended BudgetManager with per-agent tracking, CycleSnapshot with token_usage field, agent nodes tagged with agent_id, and replay CLI rendering token data.
</objective>
