    Replace the entire contents of `src/main.py` (currently legacy QuantumSwarm class with infinite loop importing from agents.order_router_ccxt).

    New main.py structure:
    1. Shebang + docstring
    2. Import argparse, asyncio, json, logging, sys
    3. IMMEDIATELY import and call configure_logging() before any other project imports. This is critical -- see Pitfall 1 in RESEARCH.md.
    4. Then import CycleRunner, reload_souls, create_orchestrator_graph, get_pool, setup_persistence
    5. `logger = logging.getLogger(__name__)`

    6. `def _try_get_pool()`:
       - Try `get_pool()`, return pool on success
       - Catch Exception, log warning "PostgreSQL unavailable, running without DB persistence", return None
       - CycleRunner already handles db_pool=None gracefully (timestamp-based IDs, no-op DB updates)

    7. `async def _run(symbol: str, mode: str) -> CycleSnapshot`:
       - pool = _try_get_pool()
       - if pool: await setup_persistence(pool)
       - graph = create_orchestrator_graph({})
       - runner = CycleRunner(graph, db_pool=pool, execution_mode=mode)
       - return await runner.run_cycle(f"Analyze {symbol}", symbol)

    8. `def main()`:
       - parser = argparse.ArgumentParser(description="Quantum Swarm Pipeline Runner")
       - sub = parser.add_subparsers(dest="command")
       - analyze_parser = sub.add_parser("analyze", help="Run analysis pipeline for a symbol")
       - analyze_parser.add_argument("symbol", help="Ticker symbol (e.g. BTC, AAPL)")
       - analyze_parser.add_argument("--mode", default="paper", choices=["paper", "live"])
       - analyze_parser.add_argument("--reload-souls", action="store_true", help="Clear and re-warm soul cache")
       - args = parser.parse_args()
       - if args.command != "analyze": parser.print_help(); sys.exit(1)
       - if args.reload_souls: reload_souls()
       - try: snapshot = asyncio.run(_run(args.symbol, args.mode))
       - except Exception as exc:
         - Build error CycleSnapshot manually with status="failed", error_context with error_type+message
         - snapshot = that error snapshot
       - print(json.dumps(snapshot.model_dump(mode="json"), indent=2, default=str))
       - sys.exit(0 if snapshot.status != "failed" else 1)

    9. `if __name__ == "__main__": main()`

    PIPE-03 (message trimming): CycleRunner._build_initial_state() already starts with `messages: []` on every call. Single-shot execution (one cycle per invocation, locked decision) means messages cannot accumulate across cycles. Within a single cycle, message growth is bounded by graph topology (fixed number of nodes). Add a comment in main.py documenting this: "PIPE-03: Messages bounded by single-shot execution -- CycleRunner resets messages:[] per cycle."
